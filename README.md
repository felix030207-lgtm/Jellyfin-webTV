# Jellyfin-webTV
Eine kleine Android-TV-App, die **deine normale Jellyfin-Weboberfläche** im Vollbild öffnet. Darum funktionieren Web-Plugins wie **Bonfire** (Profilauswahl), **Media Bar Enhanced** und **Seasonal** genauso wie im Browser – mit deinen eigenen Einstellungen.  Du installierst nur diese eine App. Anklicken, Profil wählen, fertig.
